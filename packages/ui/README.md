# Dog Dash UI

Shared component library for the **Dog Dash** project, compatible with both React Native and React Native Web.

## Overview

This package contains reusable UI components that are shared between the Web and Mobile applications. It ensures visual consistency across all platforms.

## Features

- **Cross-Platform**: Works on Web (Next.js) and Mobile (Expo).
- **Styled Components**: Themeable and modular styling.
- **Styled System**: Design-system-first utilities for layout and spacing.

## Getting Started

Components are exported from `src/index.tsx`.

### Usage
```tsx
import { MyComponent } from '@dog-dash/ui';
```

## Tech Stack

- **React Native Web**: Core primitive provider.
- **Styled Components**: CSS-in-JS library.
- **Styled System**: Style utilities.
- **TypeScript**: Typed component APIs.
